# Theater — Interactive 3D Stage

A Persian-language interactive 3D theater experience built with Three.js.

## Experience
- Click the closed velvet curtain to open the stage.
- Explore 15 theater genres represented by animated 3D genre medallions.
- Click a genre to read a concise Persian explanation and well-known play examples.
- Orbit/zoom the stage with mouse, trackpad, or touch.
- Responsive desktop and mobile layout with reduced-motion support.

## Tech
Three.js, WebGL, GLTFLoader, OrbitControls, static HTML/CSS/ES modules, GitHub Pages.
